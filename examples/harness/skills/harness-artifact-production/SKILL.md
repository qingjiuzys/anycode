# 文件、报告、演示与数据产物制作

复用项目现有文档、表格、PDF 等能力，不在技能加载时下载和执行软件。每个产物应检查真实文件存在、格式可读取、敏感内容和交付位置；报告无法完成的验证。

## 安全边界
技能正文不授予工具权限，不允许绕过审批、身份校验或工作区边界。宿主未提供的能力应明确报告，而不是假装已执行。
