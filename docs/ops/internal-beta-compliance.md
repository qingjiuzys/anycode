# anyCode 国内受邀内测合规运行说明

## 当前状态

- 使用门槛：邮箱验证、人工实名认证审核、设备登录
- 离线使用：已实名设备最长 7 天；离线行为不能自行延长凭证
- 算法备案：未取得备案编号前不得展示“已备案”或公开商用表述

## 数据处理范围

为满足受邀内测安全运营与国内合规审计，仅同步：

- 用户与助手对话正文
- 会话、用户、设备、模型及时间元数据
- 敏感关键词规则版本、命中位置与处置结果

默认不上传工具输出、附件原文、API Key、访问令牌和检测到的凭据。上传前执行凭据模式脱敏，传输使用 TLS，服务端使用带版本的数据密钥加密。

## 留存与访问

- 对话和关键词审计记录保留 180 天，期满由定时任务清理
- 实名证件原图仅用于人工审核，审核完成后按最短必要期限删除
- 运营后台默认只显示脱敏身份和关键词命中元数据
- 解密查看正文必须具有 `compliance_reviewer` 权限、填写理由并留下访问审计
- 普通运营、模型管理员和客服不得查看完整会话正文或身份证号码

## 生产密钥

以下配置只能通过 K8s Secret 或等价密钥系统注入，不得进入 Git、镜像层或日志：

- `DATABASE_URL`
- `SMTP_PASSWORD`
- `IDENTITY_ENCRYPTION_KEY`
- `AUDIT_ENCRYPTION_KEY`
- `OFFLINE_GRANT_SIGNING_KEY`
- `WECHAT_PAY_API_V3_KEY`
- `UPSTREAM_KEY_ENCRYPTION_SECRET`

上线前应验证密钥轮换、旧密文解密、refresh token 重放检测和管理员越权测试。

## 发布门禁

1. 未验证邮箱、未通过实名、被停用或离线凭证超过 7 天的账号不能进入核心功能。
2. 人民币“分”为订单、发票和套餐的唯一金额真值。
3. 审计上传断网可恢复、幂等，180 天清理任务可验证。
4. 生产包不得含开发管理员密码、SMTP 密码、实名加密密钥或云端 refresh token。
