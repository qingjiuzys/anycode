## 算法基本原理

本算法是杭州灵栖智能科技有限公司（以下简称「本公司」）自主研发与集成的**统一内容生成基础能力**，面向企业数字化与知识工作场景，基于大语言模型（LLM）的语义理解与生成能力，结合检索增强（RAG）、工具调用（Tool Calling）、多模态合成与智能体编排技术，为旗下全部 AI 产品提供一致的生成合成服务。

算法核心架构分为四层：

1. **理解与生成层**：接收用户以自然语言、代码、图片、语音、结构化数据等方式提交的输入，经 Prompt 组装（含会话历史、领域知识、安全策略）后，调用大语言模型或多模态模型进行语义理解与内容生成，输出文本、代码、图像、视频、音频等合成结果。

2. **知识增强层（RAG）**：对企业文档、项目资料、业务数据库等进行分段向量化与语义检索，将检索结果注入生成上下文，提升问答准确性与领域适配性。适用于智库、灵知、anyCode 项目知识库等场景。

3. **智能体编排层**：根据模型决策动态调度工具（文件读写、网页检索、图像/视频生成、语音合成、业务 API 调用等），形成「理解—规划—执行—反馈」多轮闭环。核心实现包括 anyCode AgentRuntime、企业工作台多智能体层等。

4. **安全合规层**：在输入前注入安全策略与系统约束；对敏感操作实施用户审批或权限校验；对接阿里云内容安全等第三方审核 API；对生成结果进行显式标识与日志审计。

**基础模型来源**：本公司不自研基础大模型权重，通过接入经合规评估的第三方模型 API（如 Agnes、智谱 GLM、DeepSeek、通义千问、Ollama 本地模型等）完成推理。本公司负责算法编排、上下文管理、产品集成与安全治理。

## 算法运行机制

### 1. 统一服务架构

本基础算法以「模型网关 + 产品适配层」方式部署，同一套生成逻辑支撑多条产品线：

```
用户/企业客户 → 产品前端（Web/APP/小程序/私有化部署）
    → 产品适配层（鉴权、业务上下文、Prompt 模板）
    → 灵栖基础算法引擎（RAG 检索 / Agent 编排 / 多模态调度）
    → 模型网关（anycode.work model-gateway / Agnes API / BYOK 端点）
    → 第三方大语言模型 / 多模态模型
    → 安全过滤 + 结果标识 → 返回用户
```

### 2. 典型请求流程

1. **接入**：用户通过注册账户、企业私有化部署或受邀内测方式访问产品；
2. **鉴权**：JWT/Session/设备绑定/API Token 完成身份校验与用量计量；
3. **上下文构建**：加载会话历史、企业知识库检索结果、领域 Prompt 模板；
4. **模型推理**：经网关调用后端模型，SSE 流式或异步任务方式返回；
5. **后处理**：格式化输出、安全提示、敏感内容拦截、审计日志记录。

### 3. 部署与更新

- **公有云服务**：阿里云容器服务（华东 cn-zhangjiakou），承载 anycode.work、story.818cloud.com 等；
- **私有化交付**：Docker 一键部署至客户内网（灵栖智库、灵栖数字人、灵栖短视频、灵知等）；
- **版本迭代**：基础算法引擎随各产品版本更新，云端网关滚动发布；不涉及公众内容推荐排序。

### 4. 标识与告知

- 各产品界面展示当前所用模型名称与提供方；
- 用户协议与隐私政策说明算法用途及数据处理方式；
- 对 AI 生成内容标注「由人工智能生成，请审慎甄别」。

## 算法目的意图

1. **统一技术底座**：以一套基础算法支撑多产品线，降低重复开发，保障安全策略一致。
2. **服务企业与开发者**：帮助客户以对话方式完成知识检索、内容创作、代码辅助与经营分析，提升数字化效率。
3. **数据主权与可控**：支持私有化部署，客户数据可留存于自有服务器；公有云场景最小必要采集。
4. **安全合规上线**：依法完成算法备案，落实主体责任，支撑在境内面向用户提供生成合成服务。
