# 打开数字工作台

anyCode 的**数字工作台**是本机网页看板：管理项目、会话、定时任务和助手产出的文件。

## macOS 桌面应用（推荐）

1. 安装 [anyCode.app](./install)
2. 打开应用 — 工作台在**应用窗口内**显示

> **说明：** 桌面版运行时，`http://127.0.0.1:43180` 主要提供 API。完整 UI 请在 **anyCode.app** 窗口中使用。

## 浏览器方式

适用于 Linux 无头安装或开发调试：

- 地址：**`http://127.0.0.1:43180`**
- 需先启动 **anyCode 桌面应用** 或 **`anycode-daemon`**

![工作台首页](/docs/assets/screenshots/home.png)
*图：浏览器打开的工作台首页*

## 第一次是空页面？

正常。请先：

1. 完成 [设置向导](./getting-started)（`/setup`）
2. 在 **项目** 中绑定一个文件夹，或新建会话发第一条消息

之后列表里就会出现数据。
