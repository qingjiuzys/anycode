# 数字工作台导览

工作台帮你回答三个问题：**哪些项目在跑？对话进行到哪？定时任务有没有失败？** 全部在本机完成，无需记命令。

![工作台首页](/docs/assets/screenshots/home.png)
*图：首页 — 快捷入口与最近动态*

## 侧栏页面一览

| 页面 | 你会看到什么 | 常见操作 |
|------|----------------|----------|
| **首页** | 快捷入口、最近会话 | 新建会话、继续上次工作 |
| **项目** | 已绑定的工作区文件夹 | 添加项目、进入项目详情 |
| **会话** | 按项目浏览对话记录 | 打开某次对话、查看时间线 |
| **同事** | 局域网内其他 anyCode 实例 | 发现同事、会话交接 |
| **自动化** | 定时任务与运行记录 | 新建 cron 任务、失败重试 |
| **产物** | 助手生成的文件索引 | 打开 PDF、表格、幻灯片等 |
| **设置** | 模型、Skills、通知、浏览器 | 改 API Key、安装技能包 |

下面按页面截图说明。

## 项目

把本地文件夹登记为「项目」后，助手才能在该目录下读写文件。

![项目列表](/docs/assets/screenshots/projects.png)
*图：项目 — 绑定工作区根目录*

## 设置

模型密钥、界面语言、内置浏览器、MCP 服务器等都在 **设置** 中配置。

![设置](/docs/assets/screenshots/settings.png)
*图：设置 — 模型与偏好*

## 自动化（定时任务）

用自然语言描述「什么时候跑、跑什么」。例如：「每个工作日 9 点，汇总昨日 git 提交」。

![自动化](/docs/assets/screenshots/automations.png)
*图：自动化 — 定时任务与运行记录*

需要任务按时触发时，请保持 **anyCode 应用** 或 **`anycode-daemon`** 在运行。

## 同事（会话交接）

同一局域网内的 anyCode 可互相发现，把会话交给另一台机器上的助手继续。

![同事](/docs/assets/screenshots/colleagues.png)
*图：同事 — 发现与交接*

## 对话里会发生什么

- **文字与图片**：在会话中直接输入；支持粘贴图片（需 Vision 模型）
- **交付物卡片**：助手生成的 PDF、Office、表格、思维导图等会以卡片出现在对话中 → 见 [会话交付物](./deliverables)
- **审批**：修改敏感文件前会弹出确认（可在设置中调整策略）

## 语言与主题

右上角切换 **中文 / English** 和浅色/深色主题。侧栏 **文档**、**帮助** 会打开对应语言的说明页。

## 出问题了？

| 现象 | 建议 |
|------|------|
| 页面打不开 | 确认 anyCode 已启动；检查 43180 端口是否被占用 |
| 列表是空的 | 先完成 `/setup`，再新建项目或会话 |
| 定时任务不跑 | 保持应用/daemon 运行；在自动化页看运行记录 |

更多见 [常见问题](./troubleshooting)。
