# 常见问题

## 安装与首次打开

**打不开工作台？**  
确认 **anyCode 应用** 已启动。浏览器用户访问 `http://127.0.0.1:43180`。若提示端口占用，关闭其他占用 43180 的进程后重试。

**设置向导（/setup）填密钥失败？**  
检查 API Key 是否正确、网络是否可访问模型服务商。改好后在 **设置 → 模型** 重新保存。

## 工作台界面

**项目/会话列表是空的？**  
先完成 [首次配置](./getting-started)，再 **新建项目** 或 **新建会话** 发一条消息。

**界面是英文的？**  
右上角语言切换选「中文」。

**页面样式异常？**  
强制刷新（Cmd+Shift+R），或重启 anyCode。

## 对话与模型

**发送后一直转圈？**  
检查网络；在 **设置** 确认模型与 API Key；查看模型服务商额度是否用尽。

**改文件前总要确认？**  
这是安全设计。可信环境可在 **设置 → 安全策略** 调整（不建议关闭全部确认）。

**想换模型？**  
**设置 → 模型** 中选择其他 provider 或模型 ID。

## 定时任务

**任务创建了但从未执行？**  
anyCode 或 `anycode-daemon` 必须保持运行。到 **自动化 → 运行记录** 查看是否有失败条目。

**显示失败？**  
点 **立即重试**；打开关联会话查看错误；把任务描述写得更具体。

## 交付物

**文件生成了但对话里没有卡片？**  
刷新会话；确认 Skill 已正确声明交付物（见 [会话交付物](./deliverables)）。

## 桌面应用（macOS）

**打开应用但窗口空白？**  
等待几秒让内置服务启动；仍不行则退出应用后重新打开。

**Dock 图标模糊？**  
使用最新 Release 安装包；必要时重启 Dock：`killall Dock`
