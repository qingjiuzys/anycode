05 · ENTERPRISE PILLARS

四根柱，缺一根就还是试点

企业要的不是「也能私有化」的口头承诺，而是和现有基础设施同构：内网能装、K8s 能跑、对象存储能接、知识能管。

01 INTRANET

内网部署

本机桌面、内网服务器或无头守护进程。业务文件默认不出域，云端只在你允许时接入。

Desktop · Daemon · 空气隔离可选
02 KUBERNETES

支持 K8s

按企业已有容器平台交付：滚动发布、健康检查、镜像仓库。信息化不用为 AI 另起一套运维宗教。

Deployment · Ingress · 私有仓库
03 OBJECT STORE

S3 企业存储

知识附件、邮件附件、Agent 产物落到企业自己的对象存储：MinIO、OSS 或任何 S3 兼容端点。

S3 API · 企业桶 · 生命周期
04 KNOWLEDGE

企业知识库

采集、切片、向量检索、带出处回答。知识不是展览柜，是 Agent 每次动手前必须经过的记忆层。

出处 · 权限范围 · 重建索引
