# Web App Template

Agent-first web MVP scaffold. The agent should:

1. Review `PRODUCT_BRIEF.md` and refine requirements with the user.
2. Implement UI and API integration under this directory.
3. Run `npm install && npm run dev` for local preview.
4. Add basic tests (`npm test` or `npm run build`) before declaring done.

Stack defaults: Vite + React + TypeScript (see `package.json`).
