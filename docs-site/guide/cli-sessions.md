# Run, REPL & TUI (removed)

These terminal session modes are **not available** after the `anycode` CLI retirement:

- `anycode run` — one-shot tasks from the shell
- `anycode repl` — line-at-a-time REPL
- Default full-screen TUI (`anycode` with no subcommand)

**Use instead:** open the [Digital Workbench](./workbench) or **anyCode.app** for multi-turn chat, tool traces, and approvals in the browser.

For automation without a UI, use Workbench **Automations**, the REST API, or `anycode-daemon scheduler`.
