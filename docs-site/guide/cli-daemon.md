# HTTP daemon (removed)

> **Note:** This page described the legacy **`anycode daemon`** HTTP server (`POST /v1/tasks`). That interface was removed per [ADR 003](https://github.com/qingjiuzys/anycode/blob/main/docs/adr/003-http-daemon-deprecated.md).

For current headless operation, see **[Headless daemon](./daemon)** (`anycode-daemon` — scheduler and channel bridges).
