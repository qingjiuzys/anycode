# 模型命令（已移除）

**`anycode model`** CLI（`list`、`status`、`set`、交互编辑）**已不再提供**。

**请改用：**

- **Workbench `/setup`** — 首次配置模型与 API Key
- **设置 → 模型** — 修改默认模型、路由与探测
- **直接编辑** — `~/.anycode/config.json`

详见 [模型与端点](./models)。

English: [Model commands (removed)](/guide/cli-model).
