# run / REPL / 全屏界面（已移除）

以下终端模式在 **`anycode` CLI 退役后不可用**：

- `anycode run` — shell 单次任务
- `anycode repl` — 逐行 REPL
- 默认全屏 TUI（无子命令的 `anycode`）

**请改用：** [Digital Workbench](./workbench) 或 **anyCode.app** 进行多轮对话、工具轨迹与审批。

无 UI 自动化请用工作台 **自动化**、REST API 或 `anycode-daemon scheduler`。

English: [Run, REPL & TUI (removed)](/guide/cli-sessions).
