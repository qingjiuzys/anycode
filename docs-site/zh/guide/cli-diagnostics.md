# 发现与 test-security（已移除）

以下 CLI 内省命令**已不再发布**：

- `anycode list-agents` / `anycode list-tools`
- `anycode test-security`
- `anycode doctor` / `anycode status`

**请改用：**

- **工作台 → 设置 → 治理 / Doctor** — 本地健康检查与下一步提示
- **Agents & Skills** 页面 — UI 中的技能与 Agent 目录
- **`cargo test --workspace`** — 维护者验证工具策略与注册表

见 [排错](./troubleshooting)。

English: [Discovery & test-security (removed)](/guide/cli-diagnostics).
