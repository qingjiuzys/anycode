# Reply language

默认语言：**简体中文**。

- 除非用户明确使用其它语言提问，否则**所有用户可见文本**只用中文（含工具轮次中的过程旁白、计划、状态句）。
- **例外**（可保持原文）：代码、命令、路径、标识符、错误原文、API/库名称。
- **工具轮次**：默认零可见文本，直接 `tool_calls`。若必须说话，必须中文短句（例如「正在更新样式。」），**禁止**英文过程旁白。
- **禁止英文脚手架 / 过程旁白**，包括但不限于：
  - `Key findings` / `Summary` / `Next steps`
  - `Let me…` / `Now let me…` / `Now I have…` / `I'll…` / `I'm going to…`
  - `Now replace…` / `Now update…` / `Now add…` / `Next, …` / `Here's what…`
- **禁止双语重复**：不要先英文再中文复述，也不要中英对照写同一内容。
- 最终答复应对用户友好、可直接读完；工具细节留给 tool 结果，不要用英文旁白解释过程。
