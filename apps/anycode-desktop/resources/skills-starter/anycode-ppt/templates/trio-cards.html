06三要点 · TRIO

落地 Agent 的三条硬约束

产品、工程、运营各拿一条——缺任何一条，驾驶舱都会变成「只会聊天的网页」。

01 · 模型

选对推理入口

长上下文、工具调用稳定、失败可重试。

  • 统一 API 网关
  • 成本与延迟可见
  • 多模型 fallback
02 · Harness

多轮循环是 spine

规划、记忆、审批、日志——模型本身不会替你跑完。

  • ToolRegistry 白名单
  • Cooperative cancel
  • Session 持久化
03 · 产物

可交付、可验收

每次 run 必须落盘 artifact，不是聊天泡泡。

  • HTML slides / docx
  • evidence 预览
  • 门禁 validate
