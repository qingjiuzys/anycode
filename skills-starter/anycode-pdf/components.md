# anycode-pdf 组件契约

## 必须章节（strict validate）

- `#` 标题（H1）
- `## Summary` 或 `## 摘要`
- ≥1 个 `##` 正文节
- 表格 ≥1（Metrics / 数据）
- `Decision:` 或 `决策：` 一行
- `Action:` 或 `行动：` + 负责人 + 日期

## 禁止词

`tbd`, `lorem`, `placeholder`, `待填`, `xxx`

## 终稿

| 文件 | 必须 |
|------|------|
| `*.pdf` | ✓ |
| `*.preview.html` | ✓ |
| `*.md` | ✓（源） |
