05对比 · VS

聊天机器人 vs Agent（带工具）

很多同学把「会写代码的 ChatGPT」当成 Agent——其实差在能不能动手并闭环。

常见误区

纯对话模型

  • 只输出文字，不执行 Shell/文件操作
  • 无法读仓库真实状态，容易幻觉路径
  • 一轮问答结束，无多步规划
  • 工具报错时无法自动重试
正确形态 · Agent

模型 + Harness + 工具

  • Read/Grep 读代码，Bash 跑测试
  • 多轮 plan → tool → observe 直到完成
  • 审批门禁拦截危险命令
  • 产物落盘：pptx / docx / 代码变更
